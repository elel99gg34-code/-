# EggMate (에그메이트)

**Steal An Egg (계란을 훔치세요)** — 로블록스 동접 1위 게임용 데스크톱 계산기.

무게·뮤테이션 수입 공식, 부화 확률, 바이옴 진입 판정, 업그레이드 회수(ROI), 퓨즈 손익을
전부 계산해 주는 Windows 앱입니다.

<br>

## 이 앱이 하지 않는 것 — 먼저 읽어 주세요

이 앱은 **로블록스 클라이언트와 전혀 상호작용하지 않습니다.** 다음 기능은 없고, 앞으로도
넣지 않습니다.

| 안 넣는 것 | 이유 |
|---|---|
| 투시(ESP) · 월핵 · 벽 너머 알/플레이어 표시 | 클라이언트 메모리 읽기나 DLL 인젝션이 필수 → 이용약관 위반, 영구정지 사유 |
| 게임 프로세스 메모리 읽기/쓰기, 인젝션 | 위와 같음 |
| 오토클릭 · 매크로 · 오토파밍 | 조작 자동화 금지 |
| 패킷 가로채기/조작 | 서버 통신 조작 금지 |
| 계정 정보 수집, 외부 전송 | 수집하지 않음 |

특히 이 게임은 **다른 플레이어의 알을 뺏는 구조**라, 투시 같은 기능은 실제 상대 플레이어에게
피해를 줍니다. "합법 투시"라는 건 존재하지 않습니다.

그리고 **"다음에 나올 레어 알"은 예측할 수 없습니다.** 부화 결과는 서버에서 굴리는 난수이고
각 시행은 서로 독립이라, 클라이언트 쪽에서 미리 알 방법이 원천적으로 없습니다. 대신 이 앱은
확률을 정확히 계산해 주고, 내가 직접 기록한 결과의 통계를 내 줍니다. 그게 실제로 도움이 되는
버전입니다.

**요약: 이 앱은 계산기이자 메모장입니다. 게임을 대신 플레이해 주지 않습니다.**

<br>

## 기능

### 1. 펫 도감
43종 펫을 바이옴·등급·수입으로 검색/필터/정렬. 한글·영문 이름 모두 검색됩니다.

### 2. 수입 계산기 — 핵심
게임이 실제로 쓰는 무게 기반 수입 공식을 그대로 구현했습니다.

```
r = 실제 무게 / 기본 무게

r  < 125 :  수입 = 기본수입 × r^(37/60)                × 뮤테이션배율
r >= 125 :  수입 = 기본수입 × 125^(13/60) × r^(2/5)     × 뮤테이션배율
```

두 식은 `r = 125` 에서 정확히 이어집니다 (`125^(13/60) × 125^(24/60) = 125^(37/60)`).
공개된 검증값(100배 → 약 17배, 200배 → 약 23배, 1000배 → 약 45배)과 일치하며,
이 검증은 테스트로 고정되어 있습니다.

- 뮤테이션 8종 동시 비교표
- 목표 수입 역산 ("1M/s 내려면 무게가 몇 배 필요한가")
- 펜 전체 합산

### 3. 확률 계산기
`0.5%` · `1/2000` · `0.005` 아무 형식으로나 입력.

- 최소 1개 나올 확률, 기대 획득 개수, 평균 대기 시도
- 50 / 90 / 95 / 99% 확신도별 필요 시도 횟수 + 예상 소요 시간
- 이항분포로 "정확히 k개 나올 확률"
- **연속 꽝 진단** — 그게 얼마나 흔한 일인지 알려주고, 다음 시도 확률은 변하지 않는다는 점을
  명시합니다 (천장 시스템 없음)

### 4. 부화 기록
직접 입력한 결과를 로컬 SQLite 에 쌓아 **내 실제 확률**을 잽니다.

- 등급별 실측 비율 + **95% 신뢰구간 (Wilson score)** — 표본이 적으면 구간이 넓게 나와서
  "아직 판단하기 이르다"는 게 눈에 보입니다
- 등급별 연속 꽝 카운터
- CSV 내보내기

데이터는 `%APPDATA%\EggMate\hatches.db` 에만 저장되고 어디로도 전송되지 않습니다.

### 5. 진행 플래너
내 스피드를 넣으면 11개 바이옴을 **안전 / 빠듯함 / 잠김**으로 판정합니다.

- 표기된 최소 스피드는 "간신히 도망칠 수 있는" 값이라 기본 안전선은 **2배**로 잡습니다
- 다음 목표 바이옴까지 부족한 스피드
- 지금 갈 수 있는 곳에서 노릴 만한 최고 수입 펫
- 업그레이드 ROI 계산 (회수 시간)
- 목표 금액 도달 시간

### 6. 퓨즈 판단
같은 펫 3마리를 합칠지 말지 손익으로 판정합니다.

- 퓨즈 전 3마리 합산 $/s vs 퓨즈 후 1마리 $/s
- **투입 펫에 뮤테이션이 붙어 있으면 수입이 늘어도 비권장** — 퓨즈하면 뮤테이션이 사라집니다
- 수수료 회수 시간, 비는 슬롯 수

## 설치

### 설치 프로그램 (권장)
[Releases](../../releases) 에서 `EggMate-x.y.z-Setup.exe` 를 받아 실행하세요.
관리자 권한 없이 설치됩니다. 설치 파일은 약 28MB 입니다.

릴리스가 아직 없다면 [Actions](../../actions/workflows/build-windows.yml) 탭에서
최신 성공 실행을 열고 Artifacts 의 `EggMate-x.y.z-Setup` 을 받으면 됩니다.

### 무설치(포터블)
같은 위치의 `EggMate-x.y.z-portable` 아티팩트를 풀고 `EggMate.exe` 를 실행하세요.

### 소스로 실행
```bash
pip install -r requirements.txt
python -m eggmate            # PYTHONPATH=src 필요
```

<br>

## 직접 빌드하기 (Windows)

```powershell
pip install -r requirements-dev.txt pyinstaller==6.11.1
python packaging\make_icon.py src\eggmate\data\icon.ico
python -m pytest tests\ -q
python packaging\smoke_test.py
pyinstaller --noconfirm --clean packaging\eggmate.spec
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /DAppVersion=1.0.0 packaging\installer.iss
```

결과물은 `dist\EggMate-1.0.0-Setup.exe` 입니다.

CI(`.github/workflows/build-windows.yml`)가 푸시마다 같은 과정을 자동으로 돌리고,
`v*` 태그를 붙이면 릴리스에 설치 파일을 첨부합니다.

<br>

## 데이터가 오래되면

게임은 자주 패치됩니다. **인게임 Index 와 업그레이드 보드가 항상 최종 기준입니다.**

값이 다르면 앱에서 직접 고칠 수 있습니다:

1. `정보` 탭 → `데이터 파일 편집용 복사본 만들기`
2. 만들어진 `%APPDATA%\EggMate\gamedata.json` 을 메모장으로 수정
3. `다시 불러오기` (또는 `Ctrl+R`)

JSON 이 깨져 있으면 앱이 조용히 기본 데이터로 되돌아가므로 앱이 못 켜지는 일은 없습니다.

<br>

## 데이터 출처

수치는 커뮤니티 위키/가이드를 교차 검증해 모았습니다. 전체 목록은 `정보` 탭이나
`src/eggmate/data/gamedata.json` 의 `sources` 필드에 있습니다.

알려진 불일치는 데이터 파일에 그대로 적어 뒀습니다:
- **Spirit Bloom** — 2.5x 로 표기한 출처와 3.0x 로 표기한 출처가 있음
- **Volcano 요구 스피드** — 70만~100만으로 출처마다 다름
- **Cosmic 등급** — 별도 티어로 세는 출처와 세지 않는 출처가 있음

현재 게임에는 **코드 리딤 시스템 자체가 없습니다.** "코드 나눠준다"는 글은 대부분 사기입니다.

## 구조

```
src/eggmate/
  core/            GUI 없는 순수 계산 로직
    income.py        무게/뮤테이션 수입 공식
    odds.py          확률, 이항분포, Wilson 신뢰구간
    planner.py       바이옴 판정, ROI, 목표 시간
    fuse.py          퓨즈 손익
    storage.py       부화 기록 SQLite
    dataset.py       gamedata.json 로딩 + 사용자 오버라이드
    fmt.py           K/M/B 및 만/억/조 표기
  ui/              PySide6 화면
    tabs/            탭 7개
  data/
    gamedata.json    출처가 붙은 게임 수치
tests/             단위 테스트 131개
packaging/         아이콘 생성, PyInstaller 스펙, Inno Setup, CI 검증 스크립트
```

계산 로직은 UI 와 완전히 분리돼 있어서 GUI 없이도 import 해 쓸 수 있습니다.

```bash
python -m pytest tests/ -q      # 131 passed
```
